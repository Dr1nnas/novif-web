How to export Asana comments

  1. Install TaskThread Export, paste an Asana Personal Access Token and tick “I agree”. The token stays in your browser.
  2. Choose a workspace and a project.
  3. Pick CSV (Excel, Markdown and PDF coming soon in Pro) and click Export with comments.
  4. The file saves straight to your computer.

FAQ

Can't Asana export comments already?

Asana's project CSV/Excel/JSON exports don't include comments. Graph exports do, but only on Enterprise plans and as raw JSON through the API.

How do I connect?

Create a Personal Access Token in Asana (My settings → Apps → Developer apps) and paste it into the extension. It is stored only in your browser’s extension storage and you can revoke it in Asana at any time. One-click sign-in is planned for a later version.

Where does my data go?

Straight from Asana's API into your browser and into the file you save. See the privacy policy.

Does it work in the Asana desktop app?

No — it's a Chrome extension, so it works in Chrome and Chromium-based browsers.

Is this made by Asana?

No. TaskThread Export is an independent tool by novif that works with Asana through its public API.
