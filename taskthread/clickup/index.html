How to export ClickUp comments

  1. Install TaskThread Export, paste your ClickUp personal API token (Settings → Apps → API Token) and tick “I agree”. The token stays in your browser.
  2. Choose Workspace → Space → List.
  3. Pick CSV (Excel, Markdown and PDF coming soon in Pro) and click Export with comments.
  4. The file saves straight to your computer.

FAQ

Doesn't ClickUp export comments already?

The List/Table view export only carries the latest comment, and the workspace export doesn't reliably include threaded replies. TaskThread Export pulls every comment and reply through the API.

How do I connect?

Generate a personal API token in ClickUp (avatar → Settings → Apps → API Token) and paste it into the extension. It is stored only in your browser’s extension storage; regenerate it in ClickUp at any time to revoke access.

Where does my data go?

Straight from ClickUp's API into your browser and into the file you save. See the privacy policy.

Is this made by ClickUp?

No. TaskThread Export is an independent tool by novif that works with ClickUp through its public API.
